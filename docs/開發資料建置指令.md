# 開發資料建置指令

> 供開發人員在本機建立測試資料，不需要真正的 LINE 帳號。

## 目標與範圍

本文件說明如何在本機環境建立下列測試資料：

* 成員（使用者）
* 家庭（Family Workspace）與成員邀請
* 記帳
* 行事曆與行程提醒
* 提醒
* 待辦與購物清單
* 儲藏庫
* LINE 訊息模擬與提醒派送

本文件只適用於本機開發與測試環境，不得用於正式環境。

## 兩種方式

| 方式 | 適用情境 | 優點 | 缺點 |
| :-- | :-- | :-- | :-- |
| 開發 API | 一般開發、驗證流程 | 走完整驗證與商業邏輯，資料一定正確 | 需逐一呼叫 |
| 直接 SQL | 大量資料、特殊狀態測試 | 一次寫入大量資料、可製造特殊狀態 | 略過驗證，可能寫入不合法資料 |

預設請使用開發 API，僅在需要大量資料或特殊狀態時才直接操作資料庫。

## 前置條件

1. 服務已依 [README.md](../README.md) 啟動：

   ```bash
   docker compose up -d --build
   ```

2. API 服務執行於 `Development` 環境。`docker-compose.yml` 已設定 `ASPNETCORE_ENVIRONMENT: Development`，不需另外調整。
3. 已安裝 `curl`。需要格式化輸出時另外安裝 `jq`。

開發專用端點（`/api/dev/*`）僅在 `Development` 與 `Testing` 環境註冊，其他環境一律回應 `404`。

## 共用設定

以下範例統一使用這些變數。Windows PowerShell 請改用 `$API = "http://localhost:8080"` 之類的寫法。

```bash
API=http://localhost:8080
COOKIE_ALICE=/tmp/nestflow-alice.txt
COOKIE_BOB=/tmp/nestflow-bob.txt
```

所有時間欄位皆為帶時區的字串，例如 `2026-08-10T14:00:00+08:00`。資料庫一律以 UTC 保存，由 API 自行換算。

## 一、建立成員

開發登入端點會在使用者不存在時自動建立使用者、外部身分與預設個人 Workspace，並回寫 Session Cookie。

```bash
curl -s -X POST "$API/api/dev/auth/login" \
  -H "Content-Type: application/json" \
  -c "$COOKIE_ALICE" \
  -d '{"externalSubject":"dev-alice","displayName":"Alice"}'
```

| 欄位 | 說明 |
| :-- | :-- |
| `externalSubject` | 模擬的 LINE 使用者識別碼。相同值代表同一位使用者，重複呼叫等同重新登入。 |
| `displayName` | 顯示名稱，每次登入都會覆寫。 |

再建立第二位成員，用於測試家庭共享：

```bash
curl -s -X POST "$API/api/dev/auth/login" \
  -H "Content-Type: application/json" \
  -c "$COOKIE_BOB" \
  -d '{"externalSubject":"dev-bob","displayName":"Bob"}'
```

確認登入結果與預設 Workspace：

```bash
curl -s -b "$COOKIE_ALICE" "$API/api/auth/me" | jq
```

後續所有請求都必須帶上對應的 Cookie 檔（`-b "$COOKIE_ALICE"`）。

### 使用瀏覽器登入

若要在 PWA（http://localhost:5173 ）上直接看到資料，可在瀏覽器開發者工具的主控台執行：

```javascript
await fetch('http://localhost:8080/api/dev/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  credentials: 'include',
  body: JSON.stringify({ externalSubject: 'dev-alice', displayName: 'Alice' }),
});
```

執行後重新整理頁面即為登入狀態。

## 二、建立家庭

### 建立 Workspace

```bash
curl -s -X POST "$API/api/workspaces" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d '{"name":"我們家","type":"family"}'
```

`type` 只接受 `personal` 或 `family`。回應中的 `id` 即為後續使用的 `workspaceId`。

取出並保存：

```bash
WS=$(curl -s -X POST "$API/api/workspaces" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d '{"name":"我們家","type":"family"}' | jq -r .id)
```

列出目前使用者的所有 Workspace：

```bash
curl -s -b "$COOKIE_ALICE" "$API/api/workspaces" | jq
```

### 產生邀請碼並加入

邀請碼為 8 碼、有效 24 小時、一次性，明文只在建立當下回傳一次，且只有家庭 Workspace 可產生。

```bash
CODE=$(curl -s -X POST "$API/api/workspaces/$WS/invitations" \
  -b "$COOKIE_ALICE" | jq -r .code)

curl -s -X POST "$API/api/workspaces/join" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_BOB" \
  -d "{\"code\":\"$CODE\"}"
```

### 查詢與管理成員

```bash
# 列出成員
curl -s -b "$COOKIE_ALICE" "$API/api/workspaces/$WS/members" | jq

# 移除成員（建立者移除他人；成員傳入自己的 Id 即為離開）
curl -s -X DELETE -b "$COOKIE_ALICE" "$API/api/workspaces/$WS/members/<userId>"
```

### 設定預設 Workspace

LINE 訊息會寫入使用者的預設 Workspace，測試家庭共享時建議先切換：

```bash
curl -s -X PUT "$API/api/workspaces/default" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d "{\"workspaceId\":\"$WS\"}"
```

## 三、建立記帳

### 分類清單

分類為固定清單，建立前可先查詢：

```bash
curl -s -b "$COOKIE_ALICE" "$API/api/account-entries/categories" | jq
```

| 類型 | 分類代碼 |
| :-- | :-- |
| 支出 `expense` | `food`、`transport`、`shopping`、`home`、`medical`、`entertainment`、`other_expense` |
| 收入 `income` | `salary`、`bonus`、`investment`、`other_income` |

分類代碼必須與 `type` 相符，否則回應 `400`。幣別支援 `TWD`、`USD`、`JPY`、`EUR`、`CNY`，省略時為 `TWD`。

### 新增

```bash
# 支出
curl -s -X POST "$API/api/account-entries" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d "{
    \"workspaceId\": \"$WS\",
    \"type\": \"expense\",
    \"amount\": 120,
    \"currency\": \"TWD\",
    \"category\": \"food\",
    \"note\": \"午餐\",
    \"occurredAt\": \"2026-08-05T12:30:00+08:00\"
  }"

# 收入
curl -s -X POST "$API/api/account-entries" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d "{
    \"workspaceId\": \"$WS\",
    \"type\": \"income\",
    \"amount\": 50000,
    \"category\": \"salary\",
    \"occurredAt\": \"2026-08-01T09:00:00+08:00\"
  }"
```

### 查詢、修改與刪除

```bash
# 區間查詢
curl -s -b "$COOKIE_ALICE" \
  "$API/api/account-entries?workspaceId=$WS&from=2026-08-01T00:00:00%2B08:00&to=2026-08-31T23:59:59%2B08:00" | jq

# 區間收支結餘
curl -s -b "$COOKIE_ALICE" \
  "$API/api/account-entries/summary?workspaceId=$WS&from=2026-08-01T00:00:00%2B08:00&to=2026-08-31T23:59:59%2B08:00" | jq

# 修改（Body 與新增相同）
curl -s -X PUT "$API/api/account-entries/<entryId>" \
  -H "Content-Type: application/json" -b "$COOKIE_ALICE" -d '{...}'

# 刪除（軟刪除）
curl -s -X DELETE -b "$COOKIE_ALICE" "$API/api/account-entries/<entryId>"
```

查詢字串中的 `+` 必須編碼為 `%2B`，否則會被解讀為空白造成時區錯誤。

## 四、建立行事曆

### 一般行程

```bash
curl -s -X POST "$API/api/calendar-events" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d "{
    \"workspaceId\": \"$WS\",
    \"title\": \"專案會議\",
    \"description\": \"季度檢討\",
    \"startAt\": \"2026-08-10T14:00:00+08:00\",
    \"endAt\": \"2026-08-10T15:30:00+08:00\",
    \"wantsReminder\": false,
    \"repeat\": false
  }"
```

`endAt` 必須晚於 `startAt`。

### 帶提醒的行程

`reminderMinutesBeforeStart` 只接受固定選項：`0`、`5`、`10`、`30`、`60`、`1440`（分鐘）。

```bash
curl -s -X POST "$API/api/calendar-events" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d "{
    \"workspaceId\": \"$WS\",
    \"title\": \"看牙醫\",
    \"startAt\": \"2026-08-12T09:00:00+08:00\",
    \"endAt\": \"2026-08-12T10:00:00+08:00\",
    \"wantsReminder\": true,
    \"reminderMinutesBeforeStart\": 30,
    \"repeat\": false
  }"
```

建立成功後會同時產生一筆對應的提醒。

### 週期行程

`repeat` 只在新增時生效，修改行程時會被忽略。`repeatEndType` 接受 `count`、`until`、`forever`。

```bash
# 重複 8 次
curl -s -X POST "$API/api/calendar-events" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d "{
    \"workspaceId\": \"$WS\",
    \"title\": \"週會\",
    \"startAt\": \"2026-08-11T10:00:00+08:00\",
    \"endAt\": \"2026-08-11T11:00:00+08:00\",
    \"wantsReminder\": false,
    \"repeat\": true,
    \"repeatEndType\": \"count\",
    \"repeatCount\": 8
  }"

# 重複到指定日期
curl -s -X POST "$API/api/calendar-events" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d "{
    \"workspaceId\": \"$WS\",
    \"title\": \"晨跑\",
    \"startAt\": \"2026-08-06T06:30:00+08:00\",
    \"endAt\": \"2026-08-06T07:00:00+08:00\",
    \"wantsReminder\": false,
    \"repeat\": true,
    \"repeatEndType\": \"until\",
    \"repeatUntil\": \"2026-09-30T23:59:59+08:00\"
  }"
```

### 查詢與刪除

```bash
# 區間查詢
curl -s -b "$COOKIE_ALICE" \
  "$API/api/calendar-events?workspaceId=$WS&from=2026-08-01T00:00:00%2B08:00&to=2026-08-31T23:59:59%2B08:00" | jq

# 刪除單場
curl -s -X DELETE -b "$COOKIE_ALICE" "$API/api/calendar-events/<eventId>"

# 刪除整個週期系列
curl -s -X DELETE -b "$COOKIE_ALICE" "$API/api/calendar-events/<eventId>/series"
```

## 五、建立提醒

不掛在行程上的自由提醒：

```bash
curl -s -X POST "$API/api/reminders" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d "{
    \"workspaceId\": \"$WS\",
    \"content\": \"繳電費\",
    \"triggerAt\": \"2026-08-15T09:00:00+08:00\"
  }"
```

查詢與取消：

```bash
curl -s -b "$COOKIE_ALICE" \
  "$API/api/reminders?workspaceId=$WS&from=2026-08-01T00:00:00%2B08:00&to=2026-08-31T23:59:59%2B08:00" | jq

curl -s -X DELETE -b "$COOKIE_ALICE" "$API/api/reminders/<reminderId>"
```

### 立即觸發派送

正式環境由 Worker 定期掃描，開發時可手動觸發，不必等排程：

```bash
curl -s -X POST "$API/api/dev/reminders/dispatch" | jq
```

只會處理已到期（`triggerAt` 小於等於現在）且狀態為 `Pending` 的提醒。未設定 LINE Messaging Channel，或使用者是由開發登入建立時，實際推播會失敗，提醒會累加重試次數並在達上限後轉為 `Failed`。若只需要驗證派送流程，觀察狀態變化即可。

## 六、建立待辦與購物清單

`type` 只接受 `general` 或 `shopping`，`quantity` 只用於購物清單。

```bash
# 一般代辦
curl -s -X POST "$API/api/todos" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d "{
    \"workspaceId\": \"$WS\",
    \"type\": \"general\",
    \"title\": \"繳停車費\",
    \"dueAt\": \"2026-08-20T18:00:00+08:00\"
  }"

# 購物清單
curl -s -X POST "$API/api/todos" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d "{
    \"workspaceId\": \"$WS\",
    \"type\": \"shopping\",
    \"title\": \"牛奶\",
    \"quantity\": 2
  }"
```

查詢、完成與刪除：

```bash
# 查詢（completed 省略時同時回傳未完成與已完成）
curl -s -b "$COOKIE_ALICE" "$API/api/todos?workspaceId=$WS&type=shopping" | jq

# 標記完成／取消完成
curl -s -X PATCH "$API/api/todos/<todoId>/completion" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d '{"completed":true}'

curl -s -X DELETE -b "$COOKIE_ALICE" "$API/api/todos/<todoId>"
```

## 七、建立儲藏庫物品

`location` 為必填。

```bash
curl -s -X POST "$API/api/storage-items" \
  -H "Content-Type: application/json" \
  -b "$COOKIE_ALICE" \
  -d "{
    \"workspaceId\": \"$WS\",
    \"name\": \"護照\",
    \"location\": \"書房抽屜第二層\",
    \"note\": \"2030 到期\"
  }"
```

查詢與刪除：

```bash
# 關鍵字可省略，省略時為最近更新列表
curl -s -b "$COOKIE_ALICE" "$API/api/storage-items?workspaceId=$WS&keyword=護照" | jq

curl -s -X DELETE -b "$COOKIE_ALICE" "$API/api/storage-items/<itemId>"
```

## 八、模擬 LINE 訊息

不需要 Messaging API Channel，也不需要真正的 LINE 帳號，即可測試完整的解析、待確認與寫入流程。`externalUserId` 使用與開發登入相同的值即代表同一位使用者，訊息會寫入該使用者的預設 Workspace。

```bash
# 記帳（記帳視同支出）
curl -s -X POST "$API/api/dev/line/message" \
  -H "Content-Type: application/json" \
  -d '{"externalUserId":"dev-alice","text":"記帳 午餐 120"}'

# 解析後回覆待確認，再送出確認才會寫入
curl -s -X POST "$API/api/dev/line/message" \
  -H "Content-Type: application/json" \
  -d '{"externalUserId":"dev-alice","text":"確認"}'
```

常用固定格式：

| 指令 | 說明 |
| :-- | :-- |
| `記帳 午餐 120` | 新增支出 |
| `支出 交通 60 捷運` | 新增支出並帶備註 |
| `收入 薪資 50000` | 新增收入 |
| `行程 明天 14:00 開會` | 新增行程，未指定結束時間時預設一小時 |
| `行程 8/10 14:00-15:30 專案會議` | 新增指定區間的行程 |
| `確認` / `取消` | 確認或取消待確認動作 |
| `說明` | 顯示可用指令 |

傳入相同的 `eventId` 可測試冪等行為，同一事件只會被處理一次：

```bash
curl -s -X POST "$API/api/dev/line/message" \
  -H "Content-Type: application/json" \
  -d '{"externalUserId":"dev-alice","text":"記帳 晚餐 250","eventId":"fixed-event-1"}'
```

## 九、一鍵建立完整測試資料

以下腳本會建立兩位成員、一個家庭、並在家庭內建立各模組的測試資料。存成 `seed.sh` 後執行 `bash seed.sh`。

```bash
#!/usr/bin/env bash
set -euo pipefail

API=${API:-http://localhost:8080}
ALICE=$(mktemp)
BOB=$(mktemp)

login() {
  curl -s -X POST "$API/api/dev/auth/login" \
    -H "Content-Type: application/json" -c "$2" \
    -d "{\"externalSubject\":\"$1\",\"displayName\":\"$3\"}" > /dev/null
}

post() {
  curl -s -X POST "$API$1" -H "Content-Type: application/json" -b "$2" -d "$3"
}

login dev-alice "$ALICE" Alice
login dev-bob "$BOB" Bob

WS=$(post /api/workspaces "$ALICE" '{"name":"我們家","type":"family"}' | jq -r .id)
CODE=$(curl -s -X POST "$API/api/workspaces/$WS/invitations" -b "$ALICE" | jq -r .code)
post /api/workspaces/join "$BOB" "{\"code\":\"$CODE\"}" > /dev/null
curl -s -X PUT "$API/api/workspaces/default" -H "Content-Type: application/json" \
  -b "$ALICE" -d "{\"workspaceId\":\"$WS\"}" > /dev/null

# 記帳
post /api/account-entries "$ALICE" "{\"workspaceId\":\"$WS\",\"type\":\"expense\",\"amount\":120,\"category\":\"food\",\"note\":\"午餐\",\"occurredAt\":\"2026-08-05T12:30:00+08:00\"}" > /dev/null
post /api/account-entries "$ALICE" "{\"workspaceId\":\"$WS\",\"type\":\"expense\",\"amount\":60,\"category\":\"transport\",\"note\":\"捷運\",\"occurredAt\":\"2026-08-05T08:10:00+08:00\"}" > /dev/null
post /api/account-entries "$BOB" "{\"workspaceId\":\"$WS\",\"type\":\"income\",\"amount\":50000,\"category\":\"salary\",\"occurredAt\":\"2026-08-01T09:00:00+08:00\"}" > /dev/null

# 行事曆（含提醒與週期）
post /api/calendar-events "$ALICE" "{\"workspaceId\":\"$WS\",\"title\":\"專案會議\",\"startAt\":\"2026-08-10T14:00:00+08:00\",\"endAt\":\"2026-08-10T15:30:00+08:00\",\"wantsReminder\":true,\"reminderMinutesBeforeStart\":30,\"repeat\":false}" > /dev/null
post /api/calendar-events "$ALICE" "{\"workspaceId\":\"$WS\",\"title\":\"週會\",\"startAt\":\"2026-08-11T10:00:00+08:00\",\"endAt\":\"2026-08-11T11:00:00+08:00\",\"wantsReminder\":false,\"repeat\":true,\"repeatEndType\":\"count\",\"repeatCount\":8}" > /dev/null

# 提醒
post /api/reminders "$ALICE" "{\"workspaceId\":\"$WS\",\"content\":\"繳電費\",\"triggerAt\":\"2026-08-15T09:00:00+08:00\"}" > /dev/null

# 待辦與購物清單
post /api/todos "$ALICE" "{\"workspaceId\":\"$WS\",\"type\":\"general\",\"title\":\"繳停車費\",\"dueAt\":\"2026-08-20T18:00:00+08:00\"}" > /dev/null
post /api/todos "$BOB" "{\"workspaceId\":\"$WS\",\"type\":\"shopping\",\"title\":\"牛奶\",\"quantity\":2}" > /dev/null

# 儲藏庫
post /api/storage-items "$ALICE" "{\"workspaceId\":\"$WS\",\"name\":\"護照\",\"location\":\"書房抽屜第二層\",\"note\":\"2030 到期\"}" > /dev/null

echo "workspaceId: $WS"
echo "alice cookie: $ALICE"
echo "bob cookie:   $BOB"
```

## 十、直接操作資料庫

需要大量資料或製造特殊狀態時，可直接連線 SQL Server。

### 連線

```bash
SA_PASSWORD='<.env 中的 MSSQL_SA_PASSWORD>'

docker compose exec sqlserver /opt/mssql-tools18/bin/sqlcmd \
  -S localhost -U sa -P "$SA_PASSWORD" -C -d NestFlow \
  -Q "SELECT id, display_name FROM users"
```

`docker compose exec` 不會經過 Shell，密碼必須由本機端展開，因此請先設定 `SA_PASSWORD` 變數，不可直接寫 `$MSSQL_SA_PASSWORD`。使用外部工具（SSMS、Azure Data Studio、DBeaver）時，連線至 `localhost,1433`，帳號 `sa`，並勾選信任伺服器憑證。

### 資料表對照

實體一律以 snake_case 對應資料表與欄位。列舉值以字串保存，大小寫必須與程式中的列舉名稱完全相同。

| 資料表 | 用途 | 主要欄位 |
| :-- | :-- | :-- |
| `users` | 成員 | `display_name`、`default_workspace_id`、`time_zone`、`notifications_enabled`、`status` |
| `external_identities` | LINE 身分綁定 | `user_id`、`provider`、`channel_id`、`external_subject`、`external_subject_hash` |
| `sessions` | 登入 Session | `user_id`、`token_hash`、`expires_at`、`revoked_at` |
| `workspaces` | 個人與家庭空間 | `owner_user_id`、`name`、`type`、`status` |
| `workspace_memberships` | 成員資格 | `workspace_id`、`user_id`、`membership_type`、`status`、`joined_at` |
| `workspace_invitations` | 邀請碼 | `workspace_id`、`code_hash`、`expires_at`、`used_at`、`status` |
| `account_entries` | 記帳 | `type`、`amount`、`currency`、`category`、`note`、`occurred_at`、`status` |
| `calendar_events` | 行事曆 | `title`、`description`、`start_at`、`end_at`、`recurrence_group_id`、`status` |
| `reminders` | 提醒 | `calendar_event_id`、`content`、`trigger_at`、`status`、`retry_count` |
| `todos` | 待辦與購物清單 | `type`、`title`、`quantity`、`due_at`、`completed_at`、`status` |
| `storage_items` | 儲藏庫 | `name`、`location`、`note`、`status`、`updated_at` |
| `pending_actions` | 待確認動作 | `action_type`、`payload_json`、`status`、`expires_at` |
| `processed_events` | 外部事件冪等紀錄 | `provider`、`external_event_id` |
| `binding_codes` | 身分綁定碼 | `user_id`、`code_hash`、`expires_at`、`status` |

常用列舉值：

| 欄位 | 可用值 |
| :-- | :-- |
| `workspaces.type` | `Personal`、`Family` |
| `workspace_memberships.membership_type` | `Owner`、`Member` |
| `account_entries.type` | `Expense`、`Income` |
| `todos.type` | `General`、`Shopping` |
| `reminders.status` | `Pending`、`Sending`、`Sent`、`Failed`、`Cancelled`、`Skipped` |
| 各表 `status`（軟刪除） | `Active`、`Deleted` |

所有時間欄位型別為 `datetimeoffset`，請一律以 UTC 寫入。

### 取得既有識別碼

```sql
SELECT u.id AS user_id, u.display_name, w.id AS workspace_id, w.name, w.type
FROM users u
JOIN workspace_memberships m ON m.user_id = u.id AND m.status = 'Active'
JOIN workspaces w ON w.id = m.workspace_id AND w.status = 'Active';
```

### 批次新增記帳

```sql
DECLARE @user_id uniqueidentifier = '<user_id>';
DECLARE @workspace_id uniqueidentifier = '<workspace_id>';

INSERT INTO account_entries
    (id, user_id, workspace_id, type, amount, currency, category, note, occurred_at, status, created_at)
SELECT TOP (200)
    NEWID(), @user_id, @workspace_id, 'Expense',
    100 + (ABS(CHECKSUM(NEWID())) % 900),
    'TWD',
    CHOOSE(1 + ABS(CHECKSUM(NEWID())) % 4, 'food', 'transport', 'shopping', 'home'),
    N'測試資料',
    DATEADD(day, -(ABS(CHECKSUM(NEWID())) % 60), SYSDATETIMEOFFSET()),
    'Active',
    SYSDATETIMEOFFSET()
FROM sys.all_objects;
```

### 手動加入家庭成員

略過邀請碼流程，直接建立成員資格：

```sql
INSERT INTO workspace_memberships
    (id, workspace_id, user_id, membership_type, status, joined_at)
VALUES
    (NEWID(), '<workspace_id>', '<user_id>', 'Member', 'Active', SYSDATETIMEOFFSET());
```

`workspace_id` 與 `user_id` 為唯一鍵組合，同一位使用者不可重複加入同一個 Workspace。

### 植入已知的邀請碼

資料庫只保存邀請碼的 SHA-256 雜湊，可自行植入一組固定值方便重複測試。邀請碼會先轉為大寫再計算雜湊，因此請直接使用大寫：

```sql
INSERT INTO workspace_invitations
    (id, workspace_id, code_hash, expires_at, used_at, status, created_by_user_id, created_at)
VALUES
    (NEWID(), '<workspace_id>',
     LOWER(CONVERT(varchar(64), HASHBYTES('SHA2_256', 'TESTCODE'), 2)),
     DATEADD(day, 1, SYSDATETIMEOFFSET()), NULL, 'Pending', '<owner_user_id>', SYSDATETIMEOFFSET());
```

之後即可固定使用 `TESTCODE` 加入該家庭。

### 植入已知的 Session

需要以固定 Token 呼叫 API 時，可直接植入 Session，再以 Cookie 帶入：

```sql
INSERT INTO sessions (id, user_id, token_hash, expires_at, revoked_at, created_at)
VALUES
    (NEWID(), '<user_id>',
     LOWER(CONVERT(varchar(64), HASHBYTES('SHA2_256', 'dev-token-alice'), 2)),
     DATEADD(day, 30, SYSDATETIMEOFFSET()), NULL, SYSDATETIMEOFFSET());
```

```bash
curl -s -b "nestflow_session=dev-token-alice" "$API/api/auth/me" | jq
```

### 注意事項

* `external_identities.external_subject` 為 AES-256-GCM 密文，無法以 SQL 手動產生。直接以 SQL 建立的使用者將無法解出 LINE 使用者識別碼，提醒推播會失敗。需要完整身分時，請改用開發登入建立使用者。
* 刪除一律採軟刪除，將 `status` 改為 `Deleted` 即可，不需實際刪除資料列。
* 待辦的完成狀態由 `completed_at` 是否有值決定，與 `status` 無關。
* 直接寫入資料庫會略過所有驗證，例如分類與類型是否相符、行程結束時間是否晚於開始時間。API 讀取到不合法的資料時可能出現非預期行為。

## 十一、清除測試資料

清除單一 Workspace 的資料（保留使用者與 Workspace 本身）：

```sql
DECLARE @workspace_id uniqueidentifier = '<workspace_id>';

DELETE FROM reminders WHERE workspace_id = @workspace_id;
DELETE FROM calendar_events WHERE workspace_id = @workspace_id;
DELETE FROM account_entries WHERE workspace_id = @workspace_id;
DELETE FROM todos WHERE workspace_id = @workspace_id;
DELETE FROM storage_items WHERE workspace_id = @workspace_id;
DELETE FROM pending_actions WHERE workspace_id = @workspace_id;
```

`reminders` 會參照 `calendar_events`，請依上述順序刪除。

完全重建資料庫（會刪除所有資料，包含使用者）：

```bash
docker compose down -v
docker compose up -d --build
```
